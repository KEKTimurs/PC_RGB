# RGB Wave — подсветка в стиле ROG (синий ↔ фиолетовый ↔ красный)

Программа живёт в трее и сама запускает OpenRGB в фоне. Интерфейс OpenRGB трогать не нужно,
кроме одной проверки при первой установке.

## 1. Уберите конкурентов
Закройте и уберите из автозагрузки **MSI Center / Mystic Light** и **XPG Prime**,
иначе они будут перебивать цвета.

## 2. OpenRGB (один раз)
1. Скачайте OpenRGB для Windows 64-bit с openrgb.org (zip).
2. Распакуйте в папку `OpenRGB` **рядом с RGBWave.exe**:
   ```
   RGBWave\
     RGBWave.exe
     config.json
     OpenRGB\OpenRGB.exe
   ```
3. Один раз запустите `OpenRGB.exe` **от имени администратора**, согласитесь на установку драйвера.
   Убедитесь, что во вкладке Devices есть материнка MSI и память XPG. Закройте OpenRGB.

## 3. Сборка RGBWave.exe
1. Установите Python 3.12+ с python.org (галочка **Add python.exe to PATH**).
2. Дважды кликните `build.bat`.
3. Готовый файл: `dist\RGBWave.exe` (рядом будет `config.json`).
   Перенесите оба файла в папку из пункта 2.

## 4. Запуск
Запустите `RGBWave.exe` → «Да» в окне UAC (права админа нужны для оперативки).
В трее появится круглая сине-красная иконка. Правый клик:
- **Подсветка включена** — вкл/выкл;
- **Скорость** 1–5 (как в Aura), **Яркость**;
- **Запускать вместе с Windows** — автозапуск с правами администратора;
- **Открыть config.json / лог**.

## Настройки (config.json)
| Параметр | Что делает |
|---|---|
| `colors` | цвета палитры, по порядку. Можно 2 и больше |
| `speed` | 1–5 |
| `brightness` | 0–100 |
| `wave_length` | сколько раз палитра укладывается по длине устройства (1.0 = один раз, 0.5 = плавнее) |
| `argb_leds` | **число светодиодов** на ARGB-разъёме платы (вентиляторы корпуса). 0 = не трогать |
| `fps` | кадров в секунду |
| `openrgb_path` | путь к OpenRGB.exe, если он лежит в другом месте |

После правки: в трее → **Перечитать config.json**. Для `argb_leds` — перезапустите программу.

## Если что-то не светится
- **Не светятся вентиляторы корпуса** — поставьте `argb_leds`, например 60, и перезапустите.
  Если горит лишнее/не всё — уменьшайте/увеличивайте.
- **Не светится память** — программа запущена без прав администратора.
- Откройте **лог** (`rgbwave.log`): там список всех найденных устройств и зон. Пришлите его мне.
- Антивирус может ругаться на exe из PyInstaller — это ложное срабатывание, добавьте в исключения.
